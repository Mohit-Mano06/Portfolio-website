# Portfolio Website - Mohit M

A premium single-page portfolio built with clean HTML, Tailwind CSS via CDN, custom CSS, and lightweight JavaScript animations.

## Features

- Apple-inspired minimal layout with generous whitespace
- Terminal-style hero intro with typing animation and blinking cursor
- Smooth scroll navigation and section reveal animations
- Subtle mouse-based parallax for the hero background
- Responsive layout for mobile and desktop
- Project, about, and contact sections in a clean one-page flow

## Stack

- HTML5
- Tailwind CSS
- Custom CSS animations
- Vanilla JavaScript

## Structure

```text
Portfolio-website/
├── assets/
├── css/
│   └── style.css
├── js/
│   └── script.js
├── index.html
└── README.md
```

## Run

Open `index.html` in a modern browser.
